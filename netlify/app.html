Flujo de aprendizaje

Backbone ViT (placeholder ImageNet) → embeddings cacheados → cabeza lineal 3 clases para imágenes + MIL con atención (CLAM-lite) para láminas completas. Ambos se re-entrenan con tus etiquetas. El backbone real de patología (UNI/Virchow) se enchufa sin tocar el resto.

📊 Evaluación honesta (split estratificado train/test)
🛡️ Administración (solo admin)
Qué es honesto aquí: las métricas salen de un split que la herramienta misma separa. Si el gap train/test supera 15pp se marca como posible sobreajuste. Con pocas muestras la evaluación se omite y se dice, no se finge.
